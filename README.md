# Android-приложение для защиты данных
Android-приложение для защиты пользовательских данных, разработанное в рамках дипломного проекта.

Цель проекта - объединение различных механизмов защиты данных в одно приложение.

Приложение состоит из следующих модулей:
- Менеджер паролей
- Шифрование файлов
- Сигнатурное антивирусное сканирование файлов
- Отображение информации об установленных приложениях

### Полученные навыки
- Разработка Android-приложений
- Проектирование модулей защиты информации
- Работа с криптографическими механизмами
- Безопасное хранение данных

### Используемые технологии
- Android Studio
- Kotlin

## Работа приложения
1. Аутентификация и авторизация.

    При первом открытии приложения пользователь создаёт новую учётную запись с паролем, которые благодаря использованию библиотеки EncryptedSharedPreferences сохраняются в зашифрованном виде в хранилище ключей Android Keystore, используя алгоритм шифрования AES-256.
    При каждом запуске приложения система проверяет, сохранены ли учётные данные. Если да — пользователю предлагается авторизация. 
    Также предусмотрен сброс учётной записи.
    После регистрации пользователь может активировать вход по отпечатку пальца.

2. Менеджер паролей.

    Модуль управления паролями отвечает за генерацию, безопасное хранение, отображение, копирование, а также удаление паролей для различных сервисов пользователя.
    Используется защищённая библиотека EncryptedSharedPreferences для шифрования паролей и сохранения их в безопасное хранилище мобильного устройства Keystore. При шифровании используется алгоритм шифрования AES-256.

3. Модуль шифрования файлов

    Модуль позволяет шифровать и расшифровывать файлы, используя алгоритм шифрования AES-256. Ключ шифрования создаётся, а затем сохраняется в защищённом хранилище Android Keystore.

4. Модуль антивирусного сканирования

   Данный модуль выполняет проверку файлов на вредоносное содержимое, анализируя имена файлов и их расширения, а также сравнивая хеш-функции файлов с набором известных вредоносных SHA-256 хешей. В рамках работы сканирование происходит во внутреннем хранилище созданного приложения.

   На экране пользователю отображаются имена файлов, их SHA-256 хеши, предупреждения о потенциальных угрозах и кнопка удаления, при нажатии на которую файл удаляется с устройства.

5. Модуль установленных приложений

   Модуль отображает пользователю многочисленную информацию обо всех приложениях устройства такую, как название программы, дата и время установки. Главной особенностью модуля является обнаружение потенциально опасных разрешений, запрашиваемых приложениями устройства, которые могут угрожать безопасности персональных данных пользователя, а также влияющие на производительность устройства в целом.

6. Модуль журнала событий

   Модуль журнала событий фиксирует действия пользователя ВНУТРИ данного приложения и записывает их в защищённую базу данных SQLite, зашифрованной через библиотеку SQLCipher.
